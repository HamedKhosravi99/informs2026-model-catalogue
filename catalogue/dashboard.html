Every selection procedure we tried reversed

Each line is one way of choosing something from the data — weights, a member subset, a gate, a threshold. The left end is what it scored when the choice was made and judged on the same folds; the right end is the same procedure with the choice itself moved inside the cross-validation. Every line goes the wrong way. This is why the shipped model contains no member chosen by cross-validation rank.

Build your own ensemble

Tick any set of the 60 models below and see what an equal-weight average of them actually scores — including the pretrained foundation models, the two-stage and hurdle formulations, and every modern architecture we tried. The numbers are exact, not interpolated: they come from the models' error cross-products, so each result is what you would have measured by running that combination. Try adding the best models one at a time and watch it stop helping. Conformal prediction appears in the catalogue but not here: it changes the interval, not the point forecast, so it cannot be an ensemble member. The MC-dropout sampler under uncertainty is the one uncertainty method that does emit a point forecast.
