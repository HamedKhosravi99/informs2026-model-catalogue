# NOTE (macOS): xgboost/lightgbm wheels need the OpenMP runtime (libomp.dylib),
# which is not bundled and not present on a stock system without Homebrew. This
# project obtained it from conda-forge (llvm-openmp) and patched the wheels'
# rpath with `install_name_tool -add_rpath <dir-containing-libomp.dylib> <dylib>`
# followed by `codesign -f -s -`. On Linux, `libgomp` from the system package
# manager suffices. If `import xgboost` fails with a libomp dlopen error, this
# is why.
